Images of code, with more than one snippet

tin.so makes images of code for posts, docs and slides. One image can show several files: split panes, stacked windows, and popovers that point to a word, as the hover card of an editor does. It is free and runs in your browser. Your code is not uploaded.

What it does

  • Split a window into panes, or put several windows in one image, in a row, in a column or anywhere you drag them.
  • Show a popover below a word with its own code, for example a type.
  • Highlight lines, and make parts of a line bold, italic, underlined or struck through.
  • Type the code directly in the image, and format it with Prettier.
  • Use all ray.so themes, with their frames, in dark and light mode, and 9 code fonts.
  • Show a title bar, tabs with file icons, or no window at all.
  • Set an aspect ratio for X, LinkedIn, Instagram or slides, and resize the image.
  • Save a PNG or an SVG, or copy the image. Drop an exported image into the editor to edit it again.
  • Share a link that opens the same image in the editor.

How to make an image

  1. Open the editor and type or paste your code into the image.
  2. Add a pane or a window for each file you want to show.
  3. Right-click a word to add a popover, or a line to highlight it.
  4. Choose a theme, then save the image, copy it or copy the link.

For agents

The tin CLI makes the same image as the editor, with no browser. It renders code files or a JSON spec, and it prints a link that opens the image in the editor, so a person can change it. 

tin main.ts plans.toml --tabs --theme vercel
pbpaste | tin --title main.ts --copy
tin link main.ts --open

An agent skill shows agents how to use the CLI. Agents that drive a browser can use the API on window.tin to set a spec and export an image.

Questions

How is it different from ray.so and carbon.now.sh?
It uses the themes of ray.so, but one image can show several snippets: split panes, stacked windows and popovers. It also has a CLI and an API for agents, and an exported image can be opened again in the editor.
Does my code go to a server?
No. The image is made in your browser. A link keeps the code after the # of the address, which the browser does not send to a server. When the site counts visits, it uses Cloudflare Web Analytics, which uses no cookies and does not get that part of the address.
Can I edit an image later?
Yes. An exported PNG or SVG contains its code and settings. Drop the file into the editor. The "Embed the spec" option in the export menu turns this off.
Is the source code available?
Yes, on GitHub. The themes and frame styles come from ray.so (MIT).
